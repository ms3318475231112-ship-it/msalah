# تسعير الدهان

حاسبة مساحة + تسعير دهان. تشتغل من المتصفح وتتثبت على الموبايل زي أي تطبيق، وبتشتغل من غير نت بعد أول فتح.

## الملفات
- `index.html`: التطبيق كله
- `manifest.webmanifest`: بيانات التطبيق (الاسم والأيقونة)
- `sw.js`: بيخلي التطبيق يشتغل أوفلاين
- `icon-192.png` و `icon-512.png`: الأيقونات

## الرفع على GitHub
1. اعمل Repository جديد على github.com.
2. ارفع كل الملفات دي في الجذر (Add file > Upload files).
3. من Settings > Pages اختار Branch: main و Folder: / (root) ثم Save.
4. بعد دقيقة هيظهر لك رابط زي `https://اسمك.github.io/اسم-الريبو/`.

## التثبيت على الموبايل
- أندرويد (Chrome): افتح الرابط > القائمة > "تثبيت التطبيق" / Add to Home screen.
- آيفون (Safari): مشاركة > Add to Home Screen.

## عايز ملف APK؟
افتح موقع pwabuilder.com، حط رابط GitHub Pages بتاعك، واختار Android، هيطلع لك ملف تثبيت جاهز.
